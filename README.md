Pharmaceutical Sales Analytics Dashboard using Excel Power Pivot

This project is an interactive Pharmaceutical Sales Analytics Dashboard developed in Microsoft Excel using Power Pivot, DAX, Pivot Tables, Pivot Charts, and Slicers. The dashboard is designed to transform raw pharmaceutical sales data into meaningful business insights that help analyze revenue, product performance, customer behavior, and regional sales trends.

The project uses a relational data model consisting of two connected datasets (Customers and Orders) linked through Customer_ID. Power Pivot was used to establish relationships between the tables, while DAX measures were created to calculate important business metrics such as Total Revenue, Total Cost, Product Quantity, Discount Percentage, and Revenue in Lakhs.

The dashboard provides dynamic filtering using State and Order Date Timeline slicers, allowing users to instantly analyze sales performance across different locations and time periods. KPI cards at the top display key information including Selected State, Total Revenue (Lakhs), Sales Year, and Top Selling Product Category.
